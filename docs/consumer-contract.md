# Consumer contract

This repository qualifies delivery from published Lighthouse packages without a Lighthouse source checkout. Its small reporting module summarizes supplied check observations. An unavailable observation must never count as passed. Changes must preserve the existing ProductShape and ArcShape scaffolds, repository guidance and custom Git hook configuration.

The initial provider scaffolds are retained for ownership checks. Issue #12 prepares a ProductShape contract for the already delivered summary behavior; implementation waits for explicit proposal approval and trusted apply. ArcShape remains an unadopted scaffold. This contract records the scope of this technical consumer. Installation, issue delivery, merge, package upgrade and rollback each need their own evidence.

The `tools/` utility is a consumer-owned customization retained before native workflow adoption and package upgrade.
